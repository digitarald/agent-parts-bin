# Changelog

## 0.1.0

- Package the Decide skill, standard-library Python CLI, synthetic fixtures,
  setup guide, and offline tests as a self-contained experimental plugin.
- Resolve bundled resources relative to the installed skill rather than a
  user-level installation. No personal configuration or credentials are bundled.
- Require users to configure their own Microsoft Foundry resource. No
  behavioral evals or accuracy guarantees are included.
